Marchenko–Pastur: Signal vs Noise —
Load data
Random matrix theory. If asset returns were pure noise, the eigenvalues of the sample correlation matrix would lie inside the bulk [λ−, λ+] = (1 ± √q)2 with q = p / n (assets / observations). Eigenvalues that escape λ+ carry statistical signal — the market factor, sectors, or persistent risk modes. The shaded curve is the theoretical Marchenko–Pastur density; ticks below mark the empirical eigenvalues. The wider the gap between the largest eigenvalue and λ+, the stronger the dominant factor.

Feasible Set — Monte Carlo N:
Load data
How it works. We sample N long-only portfolios with weights drawn from a uniform Dirichlet(1,…,1) distribution (i.e. every long-only allocation summing to 100% is equally likely). For each one we plot (σ, μ) and color it by Sharpe (μ − rf)/σ.
N  controls the number of random portfolios — bigger N gives a denser cloud that fills out the feasible region but costs more compute. Resample redraws a fresh batch with new random seeds (the cloud shape stays similar but the exact dots move). The black curve is the efficient frontier (the upper-left boundary of the cloud); the colored dots are the closed-form special portfolios (Min Var, Tangency, Mean-Var, Risk Parity); the gold ★ marks the highest-Sharpe random sample. Hover anything for details.
